# Local release / Publicação manual

No remote repository has been created and no push has been performed.

1. Sign into GitHub Desktop as **TommasoNagliatti**.
2. Choose **File → Add local repository**, select the local **GIE** folder, then **Add repository**.
3. Review the local commit on branch **main**.
4. Decide the license before public redistribution; see [LICENSE_NOTICE](../LICENSE_NOTICE.md).
5. Click **Publish repository**. Set name **GIE**, Organization **None** (personal account), and review visibility. For a public portfolio, deselect **Keep this code private**.
6. Only your final click on **Publish Repository** publishes to **TommasoNagliatti/GIE**.

Em português: adicione a pasta GIE ao GitHub Desktop, confira o commit e a branch main, defina a licença e publique manualmente com nome GIE na conta pessoal. Nada foi publicado automaticamente.

References: [add a local repository](https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-a-repository-from-your-local-computer-to-github-desktop), [publish an existing project](https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-an-existing-project-to-github-using-github-desktop), [file size limits](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).
